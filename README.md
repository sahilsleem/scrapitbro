# ScrapItBro

> Scrap the details. Keep the photo.

ScrapItBro inspects the hidden metadata and details inside photos and lets you remove those details from a separate clean copy while keeping the original photo untouched.

All metadata extraction, inspection, and lossless cleaning happen entirely in your device's browser memory. Your photos are not sent to any external server.

## Features

- **Discover Hidden Information**: Inspect camera make, model, lens details, timestamps, GPS coordinates, and raw EXIF/IPTC/XMP payloads.
- **Lossless Metadata Cleaning**: Create clean copies with metadata removed (JPEG, PNG, WebP) without re-encoding image pixels.
- **Originals Untouched**: Original photo files remain preserved exactly as imported.
- **Client-Side Privacy**: Fully offline-capable PWA with local browser storage.
